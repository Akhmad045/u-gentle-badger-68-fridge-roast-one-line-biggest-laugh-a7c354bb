Entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on [make.fun](https://make.fun).

`main.py` writes one roast line (90 characters, no trailing newline) to `/output/entry.txt`:

> My smart fridge updated its firmware overnight and now the ice maker only makes apologies.

The program verifies its own output: it reads the file back and checks it byte for byte, and refuses to write anything outside the 1–200 character gate.
